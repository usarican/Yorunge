# Yörünge 🪐

**Yörünge**, Android geliştiricileri için tasarlanmış AI destekli adapte edilebilir mentörlük ve değerlendirme platformudur.

## 📌 Proje Amacı & Öne Çıkan Özellikler

- **Geliştirici Değerlendirmesi:** GitHub ve CV analizi ile geliştiricinin mevcut seviyesini belirler.
- **4 Eksenli Değerlendirme Modeli:**
  1. Kotlin Bilgisi (idiomaticity, coroutines/flow, sealed classes)
  2. Jetpack Compose Bilgisi (state management, recomposition, side-effects)
  3. Yazılım Prensipleri (SOLID, Clean Arch / MVI, modülerlik, test edilebilirlik)
  4. Sistem Tasarımı (ölçeklenebilirlik, mimari kararlar, mülakat senaryoları)
- **Kişiselleştirilmiş Yol Haritası & Görevler:** Seviyeye uygun günlük/haftalık somut görevler atar ve GitHub üzerinden tamamlanma durumunu kontrol eder.
- **Güncel Bilgi Tabanı (RAG):** Güncel Android, Kotlin, KMP ve AI-Assisted geliştirme pratikleri ile beslenen mentörlük desteği.

## 🏗️ Proje Yapısı (Monorepo)

- `docs/`: Proje dokümantasyonu, ürün planı, araştırma notları ve tasarım sistemi.
- `backend/`: FastAPI + LangGraph + Claude API tabanlı backend ve agent servisleri (Yakında).
- `frontend/`: Next.js (React + TypeScript) tabanlı web arayüzü (Yakında).
